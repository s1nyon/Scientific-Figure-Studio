# 布局规范

- `compact` 用于单个小型结果图，`standard` 用于常规论文图，`wide` 用于横向趋势或空间关系，`composite` 用于主辅面板。
- 简单问题使用单面板；只有每个子图都承担独立证据时才使用多面板。
- 多面板优先使用 GridSpec 或 subplot_mosaic，面板标签统一放在左上角并保持对齐。
- 导出默认保留设定的物理尺寸，不依赖 `bbox_inches="tight"` 改变页面尺寸。
- 通过最终插入尺寸预览字体、刻度、图例和标注；不能只在大画布上判断可读性。
- 视觉重点由数据位置、线宽、饱和度和注释层次表达，减少无科学含义的装饰。
