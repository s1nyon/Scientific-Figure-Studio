# 布局参考

这些是根据科学任务选择的检查项，不是所有 Figure 必须遵守的固定版式。

- `compact`、`standard`、`wide` 和 `composite` 只是画布参考；依据数据密度、目标插入尺寸和证据关系选择。
- 如果一个主要结果已经回答问题，单面板通常更清楚；只有当每个子图承担不同科学任务时才组合多面板。
- 多面板可使用 GridSpec 或 subplot_mosaic，但列宽、行高、面板标签和共享坐标应服务于信息层级，而不是为了填满画布。
- 直接标签、图例、标记、线型和颜色的选择取决于类别数量、曲线位置、标签密度和读者阅读路径。
- 长句解释、设计背景和限制优先放入图注或 README；单位、目标方向和理解数据所需的关键标注仍要保留在图内。
- 导出默认保留设定的物理尺寸，不依赖 `bbox_inches="tight"` 静默改变页面尺寸；如确需使用，应记录原因并检查最终尺寸。
- 必须在预期论文插入尺寸预览字体、刻度、图例、标注和面板间距，不能只在大画布或全屏 PNG 上判断可读性。
- 视觉重点由数据位置、线宽、对比度和注释层次表达；不要用装饰、裁切或坐标比例制造数据没有支持的结论。
