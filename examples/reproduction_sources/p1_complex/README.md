# P1 independent complex reproduction

This is a self-contained two-panel practice Figure derived from the repository's
Nature-first design contract. The package contains a complete local renderer,
configuration, input table, data manifest, and brief. Nature Skill files are not a
runtime dependency; the design note is carried as provenance only.

Run with Python 3.11 and the dependencies recorded in `reproduction_manifest.json`:

    python plot.py --output-dir ./rerender
