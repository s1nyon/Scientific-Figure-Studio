# 算法流程图插图模板

这是 `illustrative example structure` 与 `illustrative practice data` 示例，不代表真实算法、比赛结果或性能结论。节点、方向、分支标签和回路全部来自 `examples/data/illustration_flowchart.json`；绘图代码不会自行增加模块或连接。

运行：

```powershell
python templates/illustration/flowchart/plot.py
```

输出目录为 `examples/outputs/fig_08_illustration_flowchart/`，包含 PNG、SVG、PDF 和 provenance manifest。修改 `config.py` 中的节点尺寸、颜色、字号或坐标范围后重新运行即可。
