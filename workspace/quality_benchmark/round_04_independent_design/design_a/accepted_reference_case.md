# Accepted Reference Case — Round 04 Design A

## Status and provenance

- Classification: personal accepted reference case.
- Source: Scientific Figure Studio Round 04 independent design test, Design A.
- Data status: `illustrative practice data`; not a real experiment, competition result, or validated scientific finding.
- Acceptance scope: the user explicitly accepted the overall visual design direction and future reference value.
- Non-claims: this record does not certify top-journal publication quality, scientific result validity, a universal template, or a global aesthetic preference.

## User-confirmed design value

The user accepted the following overall design direction for future similar cases:

- A single panel can make a small set of algorithm objective trajectories immediately readable.
- The main data should remain the visual center without unnecessary support panels.
- Consistent, distinguishable colors and markers can encode algorithms without a separate legend.
- Direct endpoint labels reduce the need to search through a legend.
- The restrained structure is a useful reference for a small number of algorithm convergence or trajectory comparisons.

These are recorded as this acceptance event, not as permanent preferences for every future scientific figure.

## Technical observations and limitations

- The source data contain ten displayed iterations, but the x-axis extends to 12 to leave space for direct endpoint labels. Future figures should choose label space from the actual data density rather than copy this range.
- The y-axis states both `Objective value` and `lower is better`. A future layout may move the optimization direction to the caption, but this archived image is intentionally unchanged.
- The Proposed point at iteration 6 is a current objective of 1.04, while the historical best remains 1.02; the adjacent change is `1.04 - 1.02 = +0.02`. The source computes the direction-aware historical best and adjacent delta. The visible `+0.02` text is accurate for this input but is a task-specific annotation, not a default for other data.
- The image does not establish convergence speed, stability, robustness, general algorithm superiority, statistical significance, or performance outside the displayed window.
- No scientific-content acceptance is inferred beyond checking that this image matches the supplied practice table and its documented definitions.

## Reuse boundary

Suitable as a visual reference for:

- a small number of algorithm convergence trajectories;
- short or medium iteration windows;
- trend-focused result figures with restrained color and direct labels.

Not a direct template for:

- dense plots with many algorithms or overlapping curves;
- repeated experiments, uncertainty, or distributional comparisons;
- multi-condition or multi-objective Figures;
- architecture, spatial geometry, network, or 3-D scientific illustrations.

Any future reuse must still pass the Nature-first figure design workflow and must be adapted to the new data and claim.
